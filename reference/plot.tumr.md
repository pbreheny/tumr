# Plot a tumr object

Plot a tumr object

## Usage

``` r
# S3 method for class 'tumr'
plot(x, ...)
```

## Arguments

- x:

  A tumr object created by
  [`tumr()`](https://pbreheny.github.io/tumr/reference/tumr.md).

- ...:

  Additional arguments passed to
  [`plot_median()`](https://pbreheny.github.io/tumr/reference/plot_median.md).

## Value

A ggplot object.
